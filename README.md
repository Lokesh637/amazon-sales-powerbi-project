# 📊 Amazon Regional Sales Analysis (Power BI)

## 📌 Project Overview
This project focuses on analyzing regional sales data of Amazon using Power BI. The dashboard provides meaningful insights into revenue, profit, order count, and customer behavior across different countries and product categories.

---

## 🎯 Objectives
- Analyze sales performance across regions
- Identify top-performing countries and categories
- Visualize trends using interactive dashboards
- Support data-driven decision making

---

## 🛠 Tools & Technologies Used
- Power BI
- DAX (Data Analysis Expressions)
- Power Query
- Data Visualization Techniques

---

## 📁 Dataset Description
The dataset contains sales-related information including:
- Country
- Revenue
- Profit
- Order Count
- Category
- Ratings

Data preprocessing was performed using Power Query to clean and transform the dataset.

---

## 📊 Dashboard Features
- 💰 Total Revenue Analysis
- 📈 Total Profit Insights
- 🛒 Order Count Tracking
- 🌍 Country-wise Performance
- 📦 Category-wise Analysis
- 📅 Monthly Trends Visualization
- 🗺 Map-based Revenue Distribution
